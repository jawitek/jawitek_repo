# Na Zaspę 3 — powierzchnie biurowe do wynajęcia

Static site for the office building at ul. Na Zaspę 3 / ul. Władysława IV 5,
80-540 Gdańsk (Nowy Port), let directly by KAP Holding sp. z o.o. Served at
`/<repo>/nazaspe3/`, independent of the Kanno Noodle site at the repo root.

Built from the owner's Claude Design prototype (`Na Zaspę 3 — strona offline.html`).
All copy, room data, photography and the palette come from that design.

```
nazaspe3/
├── index.html        hero, prolog, detal, zdjęcia, lista pokoi, rzuty,
│                     lokalizacja, FAQ, kontakt, stopka
├── css/style.css     stylesheet + the responsive layer
├── js/main.js        menu, filtr/sortowanie tabeli, wybór pokoju, FAQ, formularz
└── assets/           6 photographs + favicon
```

No build step. Serve with any static host (`python3 -m http.server` locally,
GitHub Pages in production).

## How it differs from the prototype

The prototype is a React app running Claude Design's `dc-runtime` (~200 KB of
JS for a brochure page) with every style inline, and it is desktop-only. This
rebuild keeps the visual output and rewrites the mechanics:

- **No framework.** Filters, sorting, room selection, the FAQ accordion and the
  form are plain DOM code — `js/main.js`, ~180 lines.
- **The 20 room rows are in the HTML,** not generated by script, so the full
  list still renders with JavaScript disabled. `main.js` only filters, sorts
  and links a row to the contact form.
- **Responsive layer added.** Below 960 px the hero stacks (photo first), grids
  collapse and the nav becomes a burger menu; below 700 px the four-column room
  table folds into two-line cards.
- **Photos converted PNG → JPEG:** 3.3 MB → 440 KB, visually identical.

## Things that are stubbed, and why

- **Rzuty kondygnacji (2130-INW-02/03/04) and the brochure.** The PDFs were not
  in the design bundle, so the cards would have linked to 404s. They now open a
  pre-filled e-mail requesting the drawing. Drop the files into `assets/` and
  turn the cards back into direct links.
- **The contact form has no backend.** The prototype only flipped a "sent" flag
  — a real enquiry would have vanished. It now composes a pre-filled message to
  `office@kapholding.pl` in the visitor's mail client, and the confirmation
  panel says so rather than claiming the message was sent. Wiring it to a form
  service (Formspree, Netlify Forms) would make it a true form.
- **Privacy policy and cookie links** point at `www.nazaspe3.com`, as in the
  design. Those pages are not in this repo.

## Worth checking

- Room photography is low-resolution in the bundle (485 × 260 px for Fig. 05
  and 06). Higher-resolution originals would noticeably improve those cards.
- The room list is dated **sierpień 2026** in the section kicker — update it
  when availability changes, along with the rows in `index.html`.
- The map is an OpenStreetMap embed centred on 54.40175, 18.65900.
